# Result objects

All paths are relative to the package root. `.rds` files are `saveRDS` objects. The climate variable
is called `climate` in every VAR data matrix (the assembled index, or the equal-weight headline ACI
for the benchmark). Cholesky order: `climate, INDPRO, PCEPI, UNRATE, SHADOWRATE, EXUSUKx, HOUST`.

Data loader: run `source("code/funcs/load_data.R")`, then
`d <- load_specification(spec, "data", cfg)`, with
`cfg` = `CFG` from `config.R` plus `cfg$climate_name <- "climate"`. Returns `dates` (587 months,
1975-01..2025-05 without 2020-01..2021-06), `macro` (587 x 6), `bench` (587 x 7), `comps` (587 x K,
in rank space the row-sorted panel `rank_1..rank_K`), `comps_perm` (rank space: `perm[t, j]` = index
of the component at rank j), `dates_full` (605 months incl. covid), `gap_dummy`, `pre$comps`,
`pre$headline`.

- **`point_estimates/<id>.rds`** (regenerated by step 1): `id`, `spec`, `lambda`, `lambda_source`,
  `weights` (named, length K, sums to 1), `objective`, `index`, `benchmark`, `dates`, `dates_full`,
  `gap_dummy`, `macro`, `bench`, `comps`, `comps_perm`, `var_order`, `lags` (12), `end_test_date`,
  `cv` (NULL unless `RUN_CV=TRUE`), `session`.
- **`irf_bands/<id>.rds`**, **`benchmark.rds`** (supplied): `bands` (7 variables, each `irf`, `lower`,
  `upper` of length 37 = horizons 0..36, plus `cumulated`), `irf_point` (37 x 7), `var_order`,
  `n_obs`, `block_length` (8), `B_outer` (1000), `B_inner` (100), `B_se` (200), `seed`,
  `rejected_draws`. 68% pointwise percentile-t. Fresh counterparts go to `irf_bands/_recomputed/` and also record `redraws`
  (number of redraws after a non-stationary refit: outer, inner, s.e.).
- **`bootstrap/<id>_task1.rds`** (supplied): the pairs bootstrap at the final origin: `origin` (216),
  `lambda`, `weights`, `var_B` (85 x 7), `var_resid` (560 x 7), `boot$weights` (1000 x K),
  `boot$converged`, `boot$var_B`, `boot$var_resid`, `n_draws`, `n_converged`, `sample_n` (560),
  `block_length` (13). In these matrices the climate variable is named `ACI` (national and regional
  specifications) or `MOJO` (NOAA specifications). Treat it as the first variable.
- **`bootstrap/<id>_task2.rds`** (supplied): expanding windows: `origins` (1..216), `W_mat` (216 x K,
  row o = weights with the sample ending at origin o, monthly 2005-10 to 2025-03 on the covid-free
  calendar, the covid window held at its 2019-12 value), `weights_final`.
- **`bootstrap/manifest.csv`**: file inventory, dimensions, lambdas, sizes and recorded SHA-256
  hashes for the twelve supplied stability results.
- **`summary_numbers.txt`** (regenerated by step 6, `code/06_summary_numbers.R`): plain text with
  the numbers quoted in the main text and Appendices A-C, in blocks headed by the paper location
  (e.g. `[Sec. 3.2.1, Figs. 1-2]`, `[App. A.3, Fig. A.5]`): sample sizes and settings, the troughs
  of the cumulated INDPRO response and the horizons at which the 68% bands exclude zero, component
  and rank weights, bootstrap draw counts and intervals, index-band coverage, expanding-window
  shares, rank-implied usage, and a check of the NOAA aggregation tables. Weights are in percent;
  IRF horizons run h = 0..36 with h = 0 the impact month (the paper's month = h + 1). Point values
  use the main-text point estimates; intervals use the supplied bootstrap draws, as in the figures.
Directories created only on request: `irf_bands/_recomputed/` and `bootstrap/_recomputed/` (full
fresh runs), `bootstrap/_smoke/` (reduced test runs of step 3).
