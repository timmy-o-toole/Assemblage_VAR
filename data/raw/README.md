# Raw data

**GitHub version:** the raw files themselves are not included in this repository. The FRED-MD and
Wu-Xia files are in the Zenodo record (https://doi.org/10.5281/zenodo.23976450); `MANIFEST.csv`
gives their checksums.

Raw source files read by `code/00_prepare_data.R`, the optional step that rebuilds the cleaned
files in `data/` (see the section "Data preparation" in `data/README.md`). The files must be in this
folder under the names below. Files that may not be redistributed are not included: obtain them
as described and place them here. For the reproducibility checks they are provided to the data editor
confidentially (`4-confidential-data-not-for-publication.zip`). The cleaned data shipped in `data/` are sufficient to reproduce
all results in the paper. The raw files are needed only to rerun the data preparation.

The included files are the original downloads, unchanged. `MANIFEST.csv` lists every raw file
(also those not included) with its source URL, download date, size in bytes and SHA-256 checksum,
so that a file obtained from the provider can be checked against the one used.
